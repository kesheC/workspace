# 开发者痛点调研（2026-10-29）

来源：Stack Overflow Developer Survey 2026（30k 响应，"条件信任"成为主流，78.7% 认为来源可核验很重要）、
preuve.ai《Devtools Startup Ideas 2026》（66% 开发者额外时间在调试"几乎正确"的 AI 代码；
MCP 生态 10,000+ server、97M 月 SDK 下载、41% 企业已上生产）、
以及一轮独立调研（GitHub issue / SO / 论坛的真实引用，见下）。

## 已投产（第一波）
| 项目 | 方向 | 为什么值得做 |
|---|---|---|
| gitignore-doctor | .gitignore 解释 + 体检 | 现有工具只会"生成"，没人解释规则与泄漏 |
| clidoc | README 里的 CLI 输出自动同步 | 文档与真实输出漂移是普遍腐烂点 |
| jsonl-beaver | 流式 JSONL 分析 | 几个 G 的日志，jq 写不动、Python 要现写脚本 |
| envpulse | .env 漂移 + 泄漏体检 | ⚠️ 已有 dotenv-linter compare，需靠"源码扫描 + 样例文件密钥检测"差异化 |
| apidiff | API 契约 semver 判定 | oasdiff 覆盖不全、不可当库用 |

## 候选（第二波，带真实证据）
1. **scriptport** — 静态检查 package.json scripts 里 Windows 不兼容的 POSIX 语法。
   证据：vercel/ai#17951（Windows 下脚本 exit 127）、alibaba/ice#7184（rm -rf 在 PowerShell 崩）。
   空白：rimraf/shx/cross-env 是运行时补丁，npm-package-json-lint 不看 script body。
2. **winpath** — "这个仓库能在 Windows 上 clone 吗"。
   证据：Atlassian KB `error: invalid path ... con.h`；SO 63468346 大小写碰撞警告。
   空白：casecrash 只覆盖大小写/NFC，没有保留名/长路径/符号链接。
3. **dockerctx** — 离线审计 docker build 上下文体量。
   证据：Docker 论坛 "whole directory is sent to daemon looks totally dumb"；无 --dry-run 列表。
4. **cronvision** — 证明 crontab 在 DST 当天静默不跑。
   证据：dev.to "the exact minute your job just won't run"；cron-parser 从不报告"当天无有效瞬间"。
5. **npmci-why** — 精确定位 npm ci 不同步的依赖。
   证据：npm/cli#8777；npm 只给一句无包名的报错。
6. **tztrap** — 时区矩阵测试网格（本地一条命令）。
7. **mcpdrift** — MCP 配置跨客户端校验/转换（vscode 静默不加载）。
8. **porttruth** — 跨源端口真相（compose/.env/vite/README）。

## 诚实排除（已有好工具）
大小写碰撞单独做（casecrash）、AGENTS.md 腐烂（agents-lint）、i18n key 漂移、ReDoS（recheck）、
密钥扫描（gitleaks/trufflehog）、monorepo 版本对齐（syncpack）、死链（lychee）。
